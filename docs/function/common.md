**T 支持类型**：非无符号算术类型

|:-|:-|:-|

| 返回值 | `T` | 绝对值 |

| 参数名 | 类型 | 解释 |
|:-|:-|:-|
| x | `const vec<N, T>&` | 任意维度向量 |
| 返回值 | `vec<N, T>` | 逐分量绝对值 |
