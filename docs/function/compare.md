# ktm api: compare 函数

## equal_zero

**T 支持类型**：浮点类型

#### 重载 1（标量）

| 参数名 | 类型 | 解释 |
|:-|:-|:-|
| x | `T` | 标量 |
| e | `T` | 容差，默认 `epsilon<T>` |
| 返回值 | `bool` | `|x| ≤ e` |

#### 重载 2（向量）

| 参数名 | 类型 | 解释 |
|:-|:-|:-|
| x | `const vec<N, T>&` | 任意维度浮点基类型向量 |
| e | `T` | 容差，默认 `epsilon<T>` |
| 返回值 | `bool` | `reduce_add(abs(x)) ≤ e`，各分量绝对值之和足够小 |

## equal

**T 支持类型**：浮点类型

#### 重载 1（标量）

| 参数名 | 类型 | 解释 |
|:-|:-|:-|
| x | `T` | 标量 |
| y | `T` | 标量 |
| e | `T` | 容差，默认 `epsilon<T>` |
| 返回值 | `bool` | `|x − y| ≤ e` |

#### 重载 2（向量）

| 参数名 | 类型 | 解释 |
|:-|:-|:-|
| x | `const vec<N, T>&` | 任意维度浮点基类型向量 |
| y | `const vec<N, T>&` | 同型向量 |
| e | `T` | 容差，默认 `epsilon<T>` |
| 返回值 | `bool` | `equal_zero(x − y, e)` |
