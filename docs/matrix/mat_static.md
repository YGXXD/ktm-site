# ktm mat static

## from_row

T 支持类型：任意算术类型

| 参数名 | 类型 | 解释 |
|:-|:-|:-|
| rows... | `vec<Row, T>...` | Col 个行向量（每个行向量含 Row 个元素） |
| 返回值 | `mat<Row, Col, T>` | 由行向量构造的矩阵 |

## from_diag

T 支持类型：任意算术类型

| 参数名 | 类型 | 解释 |
|:-|:-|:-|
| diag | `const vec<N, T>&` | 对角线向量（方阵专用） |
| 返回值 | `mat<N, N, T>` | 对角矩阵，非对角元素为 0 |

## from_eye

T 支持类型：任意算术类型

| 参数名 | 类型 | 解释 |
|:-|:-|:-|
| 返回值 | `mat<N, N, T>` | 单位矩阵（方阵专用） |
