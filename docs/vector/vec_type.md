# ktm api: vec 类型

## 类型定义

| 类型 | 定义 | 解释 |
|:-|:-|:-|
| `vec<N, T>` | 模版类 | `N` 为维度（`N > 1`），`T` 为分量类型 |
| `fvec<N>` / `fvec2` / `fvec3` / `fvec4` | `vec<N, float>` | 单精度浮点向量 |
| `dvec<N>` / `dvec2` / `dvec3` / `dvec4` | `vec<N, double>` | 双精度浮点向量 |
| `svec<N>` / `svec2` / `svec3` / `svec4` | `vec<N, int>` | 有符号整型向量 |
| `uvec<N>` / `uvec2` / `uvec3` / `uvec4` | `vec<N, unsigned int>` | 无符号整型向量 |

## 数据成员

**T 支持类型**：任意算术类型

| 成员 | 类型 | 解释 |
|:-|:-|:-|
| x / y / z / w | `T` | 第 0~3 个分量（vec2 / vec3 / vec4 提供） |
| r / g / b / a | `T` | 同 x / y / z / w 的颜色命名别名 |
| st.e[i] | `T[N]` | 底层数组访问（任意维度可用） |

## 构造函数

**T 支持类型**：任意算术类型

#### 重载 1（默认）

| 参数名 | 类型 | 解释 |
|:-|:-|:-|
| （无参） | — | 全部分量初始化为 0 |

#### 重载 2（标量填充）

| 参数名 | 类型 | 解释 |
|:-|:-|:-|
| s | `T` | 全部分量初始化为 s |

#### 重载 3（分量列举）

| 参数名 | 类型 | 解释 |
|:-|:-|:-|
| e0, ..., e(N-1) | `T...` | 依次初始化 N 个分量 |

#### 重载 4（低维拼接）

| 参数名 | 类型 | 解释 |
|:-|:-|:-|
| v | `const vec<2, T>&` 或 `const vec<3, T>&` | 低维向量 |
| e | `T` | 拼接标量，构造 vec3 / vec4 |

#### 重载 5（类型转换）

| 参数名 | 类型 | 解释 |
|:-|:-|:-|
| v | `const vec<N, U>&` | 不同分量类型向量，逐分量静态转换 |

## swizzle

**T 支持类型**：任意算术类型

| 参数名 | 类型 | 解释 |
|:-|:-|:-|
| Ns... | `size_t...` | 编译期下标序列，每个下标须小于 N |
| 返回值 | `vec<sizeof...(Ns), T>` | 按下标序列重排分量的新向量 |

## 命名混洗（xy / xyz / wzyx 等）

**T 支持类型**：任意算术类型

| 参数名 | 类型 | 解释 |
|:-|:-|:-|
| 返回值 | `vec<2/3/4, T>` | vec2 / vec3 / vec4 提供全部分量排列的具名混洗方法（如 `xy()`、`zyx()`、`wzyx()`），支持 x/y/z/w 与 r/g/b/a 两套命名，返回对应排列的新向量 |
